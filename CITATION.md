# Citing an experimental record

Cite the package you used, rather than the collection as if it were one experiment. Each package card supplies its own `CITATION.cff`, version identity, source archive digest and reproduction scope.

For **WEXP × EMILIA INTEROP-001**, use the [package citation](experiments/emilia-interop-001/packages/pkg-001/CITATION.cff) and version DOI [10.5281/zenodo.22056151](https://doi.org/10.5281/zenodo.22056151). Concept DOI `10.5281/zenodo.22056150` identifies the INTEROP-001 record's version family; it does not identify this collection or another experiment.

The collection has no separate publication DOI and intentionally has no root `CITATION.cff`. For a statement about collection tooling or the migration, cite the exact Git commit and the relevant file or verification report. That citation does not create a new version of the archived experiment.

For **WEXP × WIMSE AAR-02 INTEROP-001**, use its [package citation](experiments/wimse-aar-02-interop-001/packages/pkg-001/CITATION.cff), package `pkg-001`, and the exact archive-bearing GitHub commit and ZIP digest identified in its [card](experiments/wimse-aar-02-interop-001/packages/pkg-001/record.json). No Zenodo DOI has been assigned to this AAR package. A later DOI, if issued, requires its own observed publication metadata; the EMILIA DOI does not identify AAR.

For **SCITT Receipt boundary 001**, use its [package citation](experiments/scitt-receipt-boundary-001/packages/pkg-001/CITATION.cff), package `pkg-001`, and the exact Git commit of the card you used; the package is prepared only and has no release, tag or DOI.

For **WEXP × EMILIA INTEROP-002**, use the [package citation](experiments/emilia-interop-002/packages/pkg-001/CITATION.cff), version `emilia-interop-002/pkg-001`, and version DOI [10.5281/zenodo.24180793](https://doi.org/10.5281/zenodo.24180793). This identifies the exact historical Candidate 003 ZIP (192089 bytes; SHA-256 `37412ba521b9bca9901b54142290356a0aedf8bc7cd635e731d7660916cf770e`), archived on 12 November 2026. Concept DOI `10.5281/zenodo.24180792` identifies the separate INTEROP-002 version family. The [license scope](experiments/emilia-interop-002/packages/pkg-001/LICENSE-SCOPE.md) distinguishes the code and vectors from narrative and background material.
