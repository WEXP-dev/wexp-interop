# Citing an experimental record

Cite the package you used, rather than the collection as if it were one experiment. Each package card supplies its own `CITATION.cff`, version identity, source archive digest and reproduction scope.

For **WEXP × EMILIA INTEROP-001**, use the [package citation](experiments/emilia-interop-001/packages/pkg-001/CITATION.cff) and version DOI [10.5281/zenodo.22056151](https://doi.org/10.5281/zenodo.22056151). Concept DOI `10.5281/zenodo.22056150` identifies the EMILIA record's version family; it does not identify this collection or another experiment.

The collection has no separate publication DOI and intentionally has no root `CITATION.cff`. For a statement about collection tooling or the migration, cite the exact Git commit and the relevant file or verification report. That citation does not create a new version of the archived experiment.

For **WEXP × WIMSE AAR-02 INTEROP-001**, use its [package citation](experiments/wimse-aar-02-interop-001/packages/pkg-001/CITATION.cff), package `pkg-001`, and the exact archive-bearing GitHub commit and ZIP digest identified in its [card](experiments/wimse-aar-02-interop-001/packages/pkg-001/record.json). No Zenodo DOI has been assigned to this AAR package. A later DOI, if issued, requires its own observed publication metadata; the EMILIA DOI does not identify AAR.
