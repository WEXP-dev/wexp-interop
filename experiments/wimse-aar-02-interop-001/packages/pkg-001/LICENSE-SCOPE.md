# Package license scope

The input snapshot's [license scope](payload/LICENSES/SCOPE.json),
[license guide](payload/LICENSES/README.md) and [NOTICE](payload/NOTICE.md)
are retained unchanged. Native AAR code and vectors retain Apache-2.0 and
upstream attribution. Local L01–L19 signed fixture derivatives retain that
Apache treatment. The exact IETF TXT retains its original notices.

The public distribution grants MIT terms to WEXP-origin pilot, consumer, HOF
and verification/observation driver code. The new run driver has an MIT SPDX
header. This is a new grant for the previously private HOF copy; it does not
assert that its historical source was already MIT.

WEXP-authored metadata, manifests, policies, reference presentation, observation
reports and prose are offered under CC BY 4.0, attributed to WEXP-dev pilot
contributors, 2026. These terms exclude underlying third-party content. The
new public reports and outer card do not replace rights attached to exact
source copies, the signed fixture derivatives or embedded IETF material.

This package has multiple scoped licenses. It does not claim one blanket
license overrides the whole archive.
