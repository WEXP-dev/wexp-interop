# Package license scope

The public package has multiple explicit scopes. These grants apply only to
rights in the specified WEXP-origin contribution; they do not override
upstream content or the historical source's terms.

| Material | Terms |
|---|---|
| WEXP-origin Python pilot, producer, consumers, HOF copy and new comparison/input-verification helpers | [MIT](MIT.txt), newly granted for this public distribution |
| WEXP-authored prose and JSON manifest/oracle/profile/policy/reference presentation | [CC BY 4.0](CC-BY-4.0.md), newly granted for this public distribution |
| Native source trees, corpora and the modified/re-signed local DSSE fixtures | [Apache-2.0](Apache-2.0.txt), with upstream attribution and modification notice retained |
| Published IETF TXT | Original BCP 78/IETF Trust notices in each exact document |
| Underlying third-party content or source-system metadata | Its original terms remain applicable |

The machine-readable [scope](SCOPE.json) pins the 172 preserved inputs and
their individual categories. [NOTICE.md](../NOTICE.md) identifies native and
local-fixture provenance and the new HOF license grant. Code bytes and
historical license declarations are unchanged.
