# Limits of this frozen public procedure

1. **Finite, closed profile.** The procedure covers the two pinned corpora and
   19 local extensions, not every possible AAR/JSON record or every Core
   capability. It reuses a partial HOF evaluator behind a closed-profile guard.
   It does not establish full Core conformance or general AAR interoperability.
2. **Authenticated report versus world truth.** A valid trusted signature and
   internally consistent digests do not independently establish execution,
   authorization, nonoccurrence or a real observation boundary. A native
   authoritative tier is the reader's internal result. No independent execution
   or authorization artifact is delivered.
3. **Oversight is limited.** Act and digest do not resolve an authenticated human
   artifact or establish human authority. Absence of oversight does not prove
   absence of human participation. L18 carries the source decision evidence
   class in facts.evaluation.evidence_class; facts.oversight.evidence_class is
   the local producer-asserted treatment. It is not a verbatim re-export of a
   separate source oversight evidence-class field.
4. **Shared code and control.** Both routes share consumer_policy.py, the chosen
   native verifier, its packaging imports and one coordinated runtime. A fresh
   clone, process or staged directory is not independent external reproduction.
   There is no adversarial OS sandbox or enforced network isolation.
5. **Known expectations.** The private reference, earlier results and oracle
   are known to the preparation team. The new pre-run commitment is prospective
   for this public composition, but is not a blind trial or an independently
   timestamped commitment to the old private expectations.
6. **N1/N2 remain bounded.** Their native corpus permits valid or indeterminate;
   the pinned reader returned valid in the supplied private reference. The
   unchanged producer uses native-record-malformed as its generic failure code
   for a non-valid native verdict, while the consumer can distinguish an
   indeterminate verdict. The procedure therefore does not demonstrate generic
   producer handling of a hypothetical indeterminate outcome. Such a new
   outcome would fail the zero-delta reference comparison and require review,
   even if the native corpus alone allows it.
7. **Collection duplicates are not normalized by the receiver.** The historical
   profile describes set comparison after duplicate elimination. The retained
   receiver sorts collection values but does not eliminate duplicate elements.
   The fixed producer outputs are duplicate-free. This replay can establish only
   those retained shapes, not acceptance of every semantically equivalent
   serialization or complete realization of that broader profile sentence.
8. **Other native limits.** The pinned Python readers reject floating-point
   values outside their implemented space. priorCommitment.sig is not verified
   because the draft does not fix its preimage. Go-reader behavior, live standing,
   key or consumption sources, timestamp anchors, oversight-record resolution
   and external remediation deadlines are not newly validated by this package.
9. **Trusted producer worlds.** Identical signed inputs produce the same bounded
   record-only decisions in the expected result. The harness has the controlled
   before/after oracle; the recipients do not. This does not demonstrate
   detection of a false producer statement from its signed record alone.
   The focal local endpoint test does not prove deployment-wide nonoccurrence
   or exclude transient effects in other systems.
10. **Meaning of the comparisons.** Sixteen output mutations test the additional
    WEXP contract. They are not extra truth detection over a native baseline
    that never receives that extra output. Matching the private reference does
    not independently establish the private run. No integration-cost,
    performance or multi-carrier advantage is measured.
11. **Identity checks have a scope.** Hashes, Git blob comparisons and the input
    freeze fix bytes relative to declared sources. They do not by themselves
    prove authorship, a trusted timestamp, correctness of a report or source
    assertions. The new comparator checks supplied result data and does not
    execute or authenticate the implementations.

The retained historical profile status and policy scenario date are explained
in EXPECTED-DELTA.md. These limits are part of the experiment; publication does
not remove them or establish IETF approval, standardization or certification.
