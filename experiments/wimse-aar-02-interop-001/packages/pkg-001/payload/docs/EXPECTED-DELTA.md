# Expected differences fixed before the public-composition run

The public package uses the same 130 pipeline cases, 16 output mutations,
two controlled worlds, source TXT, native libraries, source envelopes, local
fixtures, profile, policies, producer, Core slice, recipients and runner as
the corrected private pilot.

**The permitted semantic delta is empty.** No field inside semantic-results.json
is excluded from comparison. The comparator rejects duplicate/non-finite JSON,
preserves JSON types, compares the complete value and requires the exact known
serialized SHA-256:

    1a97015e506db61bbf481cfac3ff3c2e53186cb935b491cb190bc370a1c62ef2

This additional comparator avoids the legacy runner's Python equality behavior
where False and 0 could compare equal. The retained runner remains unchanged.
Its existing semantic projection already omits timestamps, host/runtime strings,
temporary paths and process timings. The new full observations retain them.

The exact known negative inputs are also fixed before the new run; their newly
generated bytes, IDs, base cases and hashes must match. The three generated
dispatch policies have prospective exact bytes as well.

Changes are limited to public package identity, documentation, license and
source/provenance declarations, input-lock/freeze material, and separately
recorded new execution observations. Private inventories, unrelated research,
reviews and old execution history remain private; the exact complete semantic
reference is supplied for comparison.

The inherited profile's PRIVATE_EXPERIMENTAL_BOUNDED_MAPPING atom is retained.
The policies' 2026-10-10T07:37:08Z value is fixed scenario context, not the new
run's wall-clock time. Changing either would change the hash-bound input and
require a new declared experiment, so neither is relabelled for publication.

The machine-readable rule is [EXPECTED-DELTA.json](../pre-run/EXPECTED-DELTA.json).
A failure is preserved. It cannot be made acceptable by adding an exception
after the run; a changed candidate needs a new prospective commitment.
