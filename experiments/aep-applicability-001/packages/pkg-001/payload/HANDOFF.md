one local coordinator. They share a filesystem and operator; this is not a
sandbox-enforced blind experiment or independent reproduction. AI assistance
is disclosed here; all commits use the user's Git identity.

B creates `expectations/`, DERIVATION.md and AMBIGUITIES.json, a hash inventory
and its role receipt, then finishes with commit B before C begins. B has
the same prohibition on launching Core appraisers or using their outputs.

reaction to C results.

The three commit objects establish the local chronology; they do not by
themselves establish an external reproduction or a GitHub commit carrier.
